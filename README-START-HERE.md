# WinrothMusic – uppdaterade videor och bilder

Den här versionen använder bildfiler direkt i GitHub-repots huvudmapp, precis som i din skärmbild.

- portrait.jpg visas som stor hero-bild på startsidan.
- hero-piano.png visas under About/My Story.
- illustration.png och headbang.gif används på övriga delar.
- Watch & Listen innehåller sex videor i din angivna ordning, med korrekta namn och en ny sjätte video Still Falling for You.

## GitHub
Ladda upp `index.html` och de fyra bildfilerna till huvudmappen. Behåll övriga filer. För serverfunktioner måste `functions/api/messages.js` och `functions/api/moderate.js` ligga i exakt de mapparna och D1 måste konfigureras. Betalningarna är inte aktiverade.

Om du laddar upp allt från ZIP-filen, se till att mappstrukturen bevaras.
